ZGmax – Manual

ZGmax displays technical drawings and compares two revisions (old and new). Differences are highlighted in color and numbered, and you can review, comment on and measure them one by one, then save them as an image, a PDF or a list. For automation, see the command line manual. Deutsch: Anleitung.

Shortcuts: Ctrl means ⌘ on the Mac. Single keys such as F or N work when the drawing has the focus (click into it once).

Quick start

  1. Start: open ZGmax. The start page appears; at the first start with a short introduction in three steps (Got it hides it, Help → Show introduction shows it again).
  2. Choose drawings: choose the old drawing on the left and the new one on the right, or drag both files into the window together. The comparison starts by itself. A single file is just displayed.
  3. Look: Red = only in the old drawing (removed), Blue = only in the new one (added), Gray = unchanged, Green = only moved. Mouse wheel = zoom, drag the paper = pan, F = whole drawing.
  4. Review (optional): Start review (right panel or Ctrl+Shift+R) finds the changes and shows the first one; N goes from change to change, G = checked, X = rejected. At the end Complete review.
  5. Save: Save at the top right → image, PDF or project.

Lots of small hits? Click Auto-adjust on the left. The program measures how precisely the two drawings line up and sets the tolerance and search ranges to match.

  • Several comparisons at once: File → New window (Ctrl+N). Each window is independent (own files, markups and view settings).

  • Recently used: on the start page and under File → Recently used (pairs, single files, projects).

Sensitivity and “Auto-adjust”

Tolerance is the most important setting: lines less than n pixels apart count as identical (at 200 dpi, 1 pixel is about 0.13 mm). Many thin red/blue double lines → increase; small changes missing → decrease. Minimum size: smaller differences (dust, dots) are ignored. Then click Compare; a dot (●) on the button shows that something changed since the last calculation.

Filter lines (left panel, when viewing and comparing): shows and compares only lines of a certain stroke width. Contours only (thick lines) hides dimension, leader and center lines, hatching and normal text – what remains are the object outlines; the program determines the limit from the drawing. Thin lines only shows the opposite. With Choose stroke width you enter the width in pixels from … to … (none = no limit). When viewing, the filter takes effect at once, in a comparison with Compare; the mode chip then shows · Line filter. It is saved in the project. It only works if the drawing has different line weights.

Auto-adjust measures the current pair of drawings:

  • Line threshold – separates paper and lines (important for gray or yellowed scans).
  • Tolerance – how much deviation is just “lines not lying exactly on top of each other”: the program counts the differences at tolerance 0, 1, 2 … and picks the point after which more tolerance hardly removes anything (otherwise it would swallow real changes).
  • Minimum size – from the measured line width.
  • Max. tile shift – measured: how far individual areas are still off after alignment.
  • Search ranges (tiles, shifts, hatching) – converted to the resolution (dpi).
  • Even out uneven paper – switched on for shadows or yellowed paper.

The program cannot know which change is important; the suggestions appear in the message bar and can be changed by hand at any time. Any value can be typed into the number fields, also smaller or larger than the slider allows.

Align drawings (checkbox, on by default): New is aligned to Old. Without it both lie on top of each other exactly as they are in the files (top left aligned, no scaling, no fine alignment) – e.g. for PDFs generated identically from CAD.

Edge fringes: if lines in the new drawing are offset by one pixel or scanned/rendered slightly thicker, thin red/blue fringes appear right next to gray lines. These are ignored by default (they stay gray). Separate lines at a distance from the old line remain changes. Can be switched off under Show all settings → Advanced options → Ignore edge fringes on lines.
More checks against false alarms (also in the advanced options): Check characters exactly (on by default) – letters and digits that are only rasterized slightly differently do not count as changes; a changed digit stays a change. Even out uneven paper – compensates unevenly lit paper (shadows, yellowed scans); Auto-adjust switches it on when needed. If both files are PDFs with real lines, the message bar also offers the more precise vector comparison.

Snap to lines: the pointer snaps to lines (green square); between two parallel lines the perpendicular distance is measured automatically. Hold Shift = measure freely. Measurements stay in the drawing as dimensions, can be moved with Select and changed at the white handles. They look like a drawing dimension: thin line, arrowheads, the value centred above the dimension line and parallel to it; on short dimensions it sits outside, past the arrow. The value can be dragged at its own handle (a leader line then points to the measurement). Size changes number and arrows together; the number grows with the zoom like on paper and never becomes unreadably small. Unit (mm, cm, m, in) and decimals are in the measure bar and apply to all measurements, the list and all exports.

CAD snap points: besides lines the pointer snaps to corners, intersections and end points (cross) and to circle centres (circle with cross) – just point near them.

Typing lengths and coordinates: while measuring (and for polyline/polygon) just start typing; an input field opens at the pointer: 25 = 25 from the last point towards the mouse pointer, 25<30 = 25 at 30° (counter-clockwise), @10;5 = relative to the last point, 100;50 = absolute from the origin. The unit is the one in the measure bar. Origin: right-click → Set origin here (snaps as well); the status bar then shows x/y from there (y upwards as in CAD).

Totals and counts: below the markup list are the totals of lengths and areas and the count per type – for the selection (several selected) or for all. File → Markups → Measurements and counts as CSV (Excel) saves all measurements with value, unit and page.

Are the mm correct? The conversion is mm = pixels × 25.4 ÷ dpi × scale. The program reads the resolution from the file (otherwise 200 dpi).

  • Calibrate (safest method): button Calibrate … in the measure bar. If nothing has been measured yet, measure a known distance (e.g. a dimension of the drawing) – the program then asks for its true length. After that all measurements are correct, even with a wrong resolution.
  • Enter the scale: click “Scale 1 : n” in the measure bar. For 2:1 enter 0.5.
  • From title block: reads scale, drawing number and revision from the title block at the bottom right (directly from PDF text, by text recognition for images) and offers to use the scale.

Reviewing changes

  1. Start review (button at the top of the Changes tab, Compare → Start review or Ctrl+Shift+R): finds the changes if not done yet, opens the list, shows the first open change and shows the keys at the top. Each change gets a number and a frame (as a revision cloud if you like: View → Changes as revision clouds). Only find, without the walk-through: Compare → Find changes (Ctrl+Shift+F).
  2. Next (N) jumps to the next open change and zooms to it; Previous (P) goes back.
  3. Checked (G, moves on), Rejected (X), Comment (C). The status is shown in color: ● open, ● checked, ● rejected – in the list and on the frames in the drawing.

Complete review (Compare → Complete review … or the button in the message bar): reviewer name, result (Approved, Approved with conditions, Not approved) and remark. The program records the state of every change (status, comment, dimension), the time and the checksums of both drawing files as a review record in the project and optionally saves it as PDF. A checksum (SHA-256) over the record later shows whether it was altered afterwards – a safeguard against unnoticed changes, not a qualified electronic signature. Below the list it then says “✔ Approved – name, date”; if the review state changes afterwards, it says “Review state changed since – complete again”. Compare → Review records … lists all completed reviews with a check of the checksum.

Search: the field above the list filters while typing by number (#12), type, text, dimension, description, status or comment; list, drawing and outputs then show only the hits. Esc or the cross clears it. The Markups tab has a search field as well (type, text, comment, name).

Show: “Changes” (default) shows everything except merely moved parts; you can also filter by type, “changed text only”, “changed dimensions only”, “Contours and dimensions” (only changes to thick lines, i.e. object outlines, or to dimensions – fine lines and hatching are left out) or “open”. The filter applies to the list, the drawing, the PDF report, the CSV and the image export: only what is in the list is written, deleted entries never. Clicking a row jumps into the drawing, clicking a frame selects the row; double-click edits text A/B and the description. Mark manually adds a dragged area as your own change; Delete (or Del/Backspace) removes unwanted hits; the others keep their number, Compare → Renumber changes counts from 1 again. Clicking empty paper or Esc clears the selection. Compare → Turn rejected into zones turns all rejected hits into zones that are no longer reported in later comparisons (batch too). Status and comments are saved in the project and appear in the CSV, the PDF report and the PDF with annotations – that is your review record.

Finding text

Ctrl+F (Edit → Find text …) opens the search bar above the drawing. Enter a term, e.g. H7, bore or an item number; all hits get a yellow frame, the current one a stronger one. Enter or F3 = next hit, Shift+F3 = previous, Esc closes. In a comparison you choose whether to search in New or Old; the hits are placed correctly on the result.

For PDFs with real text, that text is used (instant, exact). For scans and images, text recognition reads the text once (a few seconds up to a minute depending on size, with progress). Upper/lower case does not matter.

Layers

The Layers tab on the right is shown by default (View → Layers hides it). Single markups are hidden with the checkbox in front of their entry in the Markups tab (or right-click → Hide). Fixed layers, from top to bottom as they lie on each other: Redactions, Dimensions, Markups, Pasted images, Changes, Zones, Drawing. Each has a checkbox (visible) and a lock:

  • Visible – hidden layers appear neither on screen nor when saving, printing or copying (e.g. hide the drawing to export only the markups). Exception: redactions are always burnt in.
  • Locked – contents cannot be clicked, moved or deleted (e.g. lock dimensions while drawing clouds; a locked drawing cannot be edited).

Saving as layers: PDF with annotations creates a real PDF layer for each visible layer (toggle them in Acrobat under Layers). As SVG with layers creates layers for Inkscape, Illustrator & co.; markups and change frames are individual, editable vectors there. TIFF and PNG have no generally readable layers and are saved flat.

Layers of the PDF file: if a PDF has its own layers (e.g. dimensions, text, hidden edges from CAD), they appear below in the section Layers of the PDF file. Unticked, a layer is not drawn and – in a comparison – not compared either. The choice is saved in the project.

Text and dimensions

In the section Text and dimensions (right panel, expand it; also in the Compare menu):

  • Find changed text: reads the text of each change – also dimensions and vertical text in both reading directions – and writes “old text → new text” into the list. For PDFs with real text that text is used (exact, instant), otherwise text recognition (German and English, also Ø, ±, °). Afterwards list, drawing and PDF show only changes with changed text (filter Show: changed text only).
  • Find changed dimensions: reads the numbers of each change and compares them (also R and M values). Afterwards list, drawing and PDF show only changes in which a dimension value changed (“12.5 → 12.8”); small line changes in the geometry are hidden (filter Show: changed dimensions only). Show: Changes brings everything back.
  • Dimension changes as table (Compare or Save): all changed dimensions as PDF or CSV with number, type, dimension old → new, tolerance old and new (ISO fits such as H7/g6, ±0.1 or deviations +0.2/−0.1; a changed tolerance in red), position in mm, review status and comment – to pass on to suppliers and production. If the dimensions have not been read yet, this happens automatically first.
  • Check title block revision: reads the revision index in the title block of Old and New and warns if the drawing changed but the index stayed the same – or the other way round.
  • Grouping: how close differences must be to be combined into one entry.

Text recognition is included in the app; when running with Python the program offers to install it on first use (about 60 MB, internet needed).

Importing and passing on comments (XFDF, PDF)

Opening a PDF with comments: the comments are not drawn into the image but taken over automatically as editable markups (in a comparison those of Old and New, each at the right place) – move, change and delete them like your own. This does not happen for projects, which already contain their markups.

File → Markups → Import comments (XFDF, PDF) … takes over annotations from other programs as your own markups:

  • XFDF (comment export from Acrobat, Bluebeam, PDF-XChange …) and
  • PDF with comments (the annotations of the selected page).

Text, box, cloud, highlight, arrow, line and stamp are imported with color, author, date and comment text (visible in the markup list). In a comparison the program asks whether the comments belong to the old or the new drawing; for the new one they are transformed onto the result. Unknown types (e.g. sound, attachment) are skipped and reported.

File → Markups → Save markups as XFDF … writes your own markups and measurements as XFDF, which you can import into the original PDF in Acrobat & co. (Comments → Import).

Aligning manually (3 points)

If the drawings do not line up well after automatic alignment (e.g. a heavily distorted scan or a different sheet format), use Compare → Comparison settings → Align manually (3 points) (also a button next to Auto-adjust): click a point in Old and the same point in New, three times (the message bar says which one is next; corners or crossings far apart work best). The program then moves, rotates and scales the new drawing and compares again. Reset manual alignment undoes it. The alignment is saved in the project.

Multi-page files

Turning pages: for multi-page PDF/TIFF files the top bar shows the page selector ◀ page / count ▶: click the arrows or type the page number. Page Up / Page Down (Mac: Fn+↑/↓) go to the previous or next page, as do View → Previous page / Next page. In addition the section Pages appears on the left (with thumbnails for PDFs): click a page or set Page A / Page B separately; Turn pages of A and B together is the default. Compare all pages compares every page and writes the number of changes per page into the list (red = changed, green = identical).

Markups belong to the page: each page (in a comparison each page pair) has its own markups; they are kept while turning pages, the page list shows their count and the project saves all of them. Scale and calibration also apply per page, and so does the change list with its review state: if you review page 1, move on to page 2 and come back, status and comments are still there; the page list shows “n changes, m open” per page. Save → PDF with annotations – all pages puts every page with its markups (in a comparison: the result with changes) into one PDF; PDF change report – all pages reports on all page pairs. Both appear only for multi-page files.

Region, matching areas, zones

Visible with View → Show all settings.

  • Region: compare only part of the sheet (faster). Drag a frame in A; the matching area in B is found automatically.
  • Match areas (A ↔ B): choose an area in A and the matching area in B yourself – e.g. when a view was moved or scaled on the sheet. The program compensates for size differences.
  • Zones: areas that are not compared (title block, stamps). Click them in the drawing with Select: drag = move, corners = resize, Del or right-click = delete (also in the zone list). Border strip: exclude the sheet border.

Markups, measurements and zones belong to the sheet: when the region changes, they stay at the same place on the drawing.

PDF vector data and DXF

File formats: PNG, JPG, TIF (also multi-page), BMP, WEBP, JP2, GIF, PDF, SVG, XPS and DXF. DXF is drawn black on white from model space (unit mm; very large drawings are reduced to A0). DWG cannot be read directly – save it as DXF or PDF in your CAD program. Transparent areas (PNG with transparency) count as white paper; 16-bit and CMYK images are converted. For a password-protected PDF the program asks for the password; it applies until you quit and is not saved.

Vector data (PDF): if both PDFs contain real lines and text (from the CAD system), the section Vector data (PDF) appears on the left: Vector comparison compares line against line and text against text without rasterizing (tolerance 0.05 mm by default; both drawings need the same sheet origin). Layers and colors … chooses what is compared (e.g. everything except dimensions).

Batch and revisions

Compare folders (Compare → Compare folders (batch) …): compares all matching drawings of two folders, every page – e.g. your own release against a supplier data set. Files are matched by name; optionally in subfolders too and ignoring a revision letter at the end of the name (1234_B ↔ 1234_C). The overview shows per drawing ● changed (with count and affected pages), ● identical, only in old or only in new release, or an error; double-click opens a pair for review. The output folder receives uebersicht.pdf and uebersicht.csv, optionally a result image, CSV list and PDF report per changed sheet. Compare → Compare revisions: several revisions of a drawing in order (A → B → C …) with a change history. Both use the current settings.

Language and interface size

  • Language: View → Sprache / Language: Automatic (system language; German on a German system, otherwise English), Deutsch or English. This manual also opens in the chosen language.
  • Size: View → Interface size: 90 % to 150 % – larger text and buttons, e.g. on large screens.

Both take effect after a restart, which the program offers right away (open work is saved first).

Reset all settings (Help): appearance, language, size, comparison values, tool options and window position back to defaults; optionally the Recently used list is kept. Files, projects and markups stay unchanged.

Version and what's new: Help → What's new … shows the change history in the interface language. After an update the program points this out at the first start. The version number is shown under About ZGmax (Mac: program menu ZGmax → About ZGmax) and is stored in every project; a project from a newer version opens with a notice.

Questions

QuestionAnswer
Many small red/blue spots that are not changes.Auto-adjust; otherwise increase the tolerance by 1 or increase the minimum size.
Nothing changes after moving a control.Click Compare (or switch on Recompute automatically).
The mm values are wrong.Calibrate … in the measure bar, or enter the scale.
A markup cannot be changed.Esc (back to Select), click it, double-click = edit.
The comparison takes long / needs a lot of memory.Very large scans (over 100 megapixels) need a few seconds and several GB of memory. Stop with Cancel; compare only the relevant part with a region; for PDFs reduce the dpi (e.g. 150).
Something does not work.The message bar shows the error (Details). Help → Open log file opens the log.
