Manual: command line (drawing_diff.py)

For advanced users: drawing_diff.py runs comparisons without a window – in scripts, overnight or for many files. For normal work with the mouse see the manual. Deutsch: Anleitung Kommandozeile (more detail). The script's own messages and -h help are in German.

Run all commands in the programm folder (where drawing_diff.py is). Put paths with spaces in quotes.

1. Requirements

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt            # optional OCR: -r requirements-ocr.txt

2. Basic call

python drawing_diff.py OLD.tif NEW.tif --out diff.png
python drawing_diff.py -h                         # all options with defaults and examples
  • Image A (first) is the reference, usually the old revision. The result has the size of A.
  • Image B (second) is the new revision; it is aligned to A.
  • Sensible defaults are active: tile fine alignment, hatching suppression, detection of moved areas and objects, edge-fringe filter and minimum size.

3. File formats

Input (by extension; A and B may differ): TIFF (also multi-page and 1-bit), PNG, JPG, BMP, WebP, JPEG 2000, GIF, PDF, SVG, XPS (rendered at --dpi, default 200) and DXF (model space, black on white). DWG/STEP/JT: export as DXF, PDF or TIF first. Pages: --page-a N / --page-b N.

Output by the extension of --out or --format: png (default), tif, pdf, jpg (--quality), webp (max. 16383 px), bmp.

4. Result image

ColorMeaning
RedOnly in A (removed or changed)
BlueOnly in B (added or changed)
GrayIn both (unchanged)
GreenSame content at another place (block or single object moved or slightly rotated)

A legend with colors, file names and settings is added to the right (--no-legend to omit it).

5. Comparing only a region

python drawing_diff.py OLD.tif NEW.tif --select                     # drag in A, B is found automatically
python drawing_diff.py OLD.tif NEW.tif --select --fit manual        # choose B yourself
python drawing_diff.py OLD.tif NEW.tif --crop-a 4000,1500,4000,2500 # x,y,width,height in pixels of A

At 200 dpi, 1 pixel ≈ 0.13 mm.

7. Batch

Give two folders instead of two files: all files with the same name (ignoring extension and case) are compared.

python drawing_diff.py "D:\Drawings\old" "D:\Drawings\new" --out "D:\Results" --list --report

Errors in one pair are reported and the batch continues. Exit code 1 on errors. In the program window: File → Batch comparison.
